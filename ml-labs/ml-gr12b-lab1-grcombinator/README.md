# Название темы
Лабораторная работа №1 посвящена созданию и настройке изолированных виртуальных окружений для проектов машинного обучения с использованием Anaconda. В ходе работы я освоил установку и управление пакетами через сonda и pip, познакомился с различными средами разработки — от консольного Python до Jupyter Notebook, JupyterLab и Google Colab. Также практикуется работа с консольными утилитами curl и wget для загрузки данных, а также публикация кода через GitHub Gist. Цель — подготовить устойчивую, воспроизводимую и профессиональную среду для дальнейшего изучения машинного обучения
