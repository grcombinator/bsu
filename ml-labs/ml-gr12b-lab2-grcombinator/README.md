# Название темы
Лабораторная работа №2 по курсу «Введение в машинное обучение для промышленных IoT-решений» направлена на освоение фундаментальных принципов программирования на Python, необходимых для обработки данных в IoT-системах. В рамках работы студенты реализуют восемь практических заданий, охватывающих форматирование вывода, условные операторы, циклы, функции, объектно-ориентированное программирование и работу с файлами (CSV, бинарные данные, pickle). Каждое задание моделирует реальные задачи — от конвертации валют и вычисления расстояний до локализации объектов по сигналам и анализа транзакций — что позволяет развить навыки структурированного кодирования, работы с данными и создания надежных, документированных решений в соответствии с требованиями промышленной разработки.
